Vous possédez un code cadeau JEEP ? Entrez-le ci-dessous pour vérifier sa validité et réclamer votre récompense.

Réclamer un cadeau

Saisissez le code qui vous a été communiqué. Chaque code est soumis à ses conditions, à sa période de validité et à sa limite d'utilisation.

Comment ça marche ?

1
Obtenez un code

Utilisez un code cadeau officiellement communiqué par JEEP.

2
Entrez le code

Saisissez-le dans le champ prévu, puis appuyez sur le bouton de réclamation.

3
Vérification automatique

Le serveur vérifie le code, son expiration et si votre compte l'a déjà utilisé.

Protection de votre compte
La validation est effectuée côté serveur. Ne communiquez jamais votre mot de passe ou votre code de connexion pour recevoir un cadeau.
